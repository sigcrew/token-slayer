Token Slayer

AI 에이전트의 남은 사용량이 곧 용사의 HP예요.

  • ⚔️ 에이전트가 일하면 용사가 날아오는 코드를 베어요
  • 🔥 쉬는 동안엔 모닥불 앞에서 쉬어요
  • 💥 사용량이 줄면 한 대 맞고, 0%면 GAME OVER
  • 🧪 한도가 리셋되면 포션을 마시고 부활해요

무엇을 읽고, 어디로 보내나요?

Token Slayer에는 따로 운영하는 서버가 없어요. 아무것도 수집하지 않고, 모든 처리는 이 컴퓨터 안에서 끝나요.

ClaudeClaude Code 로그인(키체인) 또는 이 앱 안에서 한 claude.ai 로그인으로 api.anthropic.com · claude.ai에 사용량만 물어봐요
Codex~/.codex/sessions 기록 파일의 사용 한도 줄을 읽고, 로그인 토큰으로 chatgpt.com에 사용량만 물어봐요 (트레이 메뉴에서 끌 수 있어요)
CursorCursor 설정 DB의 로그인 토큰으로 cursor.com에 사용량만 물어봐요
작업 감지용사 움직임을 위해 위 앱들이 파일을 쓰는 시각만 봐요 (내용은 읽지 않아요)

로그인 토큰은 읽기만 하고, Claude Code 토큰이 만료되면 새 토큰을 원래 자리에 다시 저장해요. 대화 내용은 읽지 않아요. 각 서비스의 공식 공개 API가 아니라서, 서비스가 바뀌면 일부가 멈출 수 있어요.

어떤 용사를 데려갈까요?

이 컴퓨터에서 찾은 에이전트예요. 켜 둔 것만 화면에 나와요. 나중에 트레이 메뉴 표시할 서비스에서 바꿀 수 있어요.
